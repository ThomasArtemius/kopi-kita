# Kopi Kita

**Kopi Kita** adalah website coffee shop yang dirancang untuk memudahkan pelanggan menikmati pengalaman ngopi, sekaligus membantu pemilik toko mengelola operasional sehari-hari secara digital.

## Fitur Utama

### Untuk Pelanggan
- **Halaman Menu** — Menampilkan daftar produk kopi, makanan pendamping, dan minuman lainnya lengkap dengan deskripsi, harga, dan foto.
- **Booking Meja** — Pelanggan dapat memesan meja secara online dengan memilih tanggal, jam, dan jumlah tamu, tanpa perlu menelepon atau datang langsung.

### Untuk Pengelola (CMS)
- **Manajemen Produk** — Admin dapat menambah, mengubah, atau menghapus produk pada menu, termasuk kategori, harga, ketersediaan stok, dan gambar.
- **Manajemen Booking** — Admin dapat melihat, menyetujui, atau membatalkan reservasi meja yang masuk, serta memantau jadwal booking secara keseluruhan.

## Tujuan Proyek

Proyek ini dibuat untuk membantu coffee shop lokal mempunyai kehadiran online yang profesional, mempermudah pelanggan dalam melihat menu dan memesan meja, serta menyederhanakan proses pengelolaan produk dan reservasi bagi pemilik usaha.
